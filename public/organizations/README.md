# Organization logos

- `gdg.webp`: GDG PUP website, https://dev.gdgpup.org/branding/gdg-logo.webp
- `iecep.png`: IECEP national emblem hosted by IECEP UAE, https://iecep.ae/wp-content/uploads/2019/02/cropped-Trans-IECEP-Logo-192x192.png
- `cisco.svg` and `datacamp.svg`: copied from the installed Simple Icons package. Cisco uses the parent brand mark for the NetConnect entry.

Organization names remain visible beside the logos; image alt text is empty to avoid repeating them for screen readers. All marks belong to their respective owners.
